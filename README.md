# TechNova 🚀

Proyecto de aprendizaje y portafolio para el desarrollo de una empresa de tecnología y soluciones web modernas.

## 🛠️ Tecnologías

- Astro
- HTML
- CSS
- JavaScript
- Tailwind CSS
- Git
- GitHub

## 🎯 Objetivo

Construir una página web profesional para TechNova mientras aprendemos desarrollo web, diseño, control de versiones y buenas prácticas de programación.
